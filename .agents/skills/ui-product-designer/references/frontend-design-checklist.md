# Frontend Design Checklist

## Shell

- Keep one clear studio shell.
- Keep the viewport central.
- Keep the top bar focused on document and mode state.
- Keep side panels contextual, not decorative.

## CAD Interaction

- Prefer direct actions over menus when the command is primary.
- Open a real dialog when the command needs parameters.
- Explain blocked commands in plain language.
- Keep finish/cancel behavior explicit in sketch and feature flows.

## Visual Quality

- Use compact spacing and dense but readable controls.
- Reuse the studio theme and dialog styles before inventing new ones.
- Keep button text short and action-led.
- Use icon-led controls for tools, not text-only strips.

## Assistant

- Keep Copilot secondary.
- Show useful prompt starters when context exists.
- Keep inactive state clean and quiet.

## Review Questions

- Would this screen look credible in a public screenshot?
- Does it look like CAD software instead of a dashboard?
- Does the user know what to click next?
- If the command cannot run, is the reason visible?
