`SelectedFacePlane`) is `[JsonIgnore]`- File extension: `.umxproj`- Autosave path: `%APPDATA%/My3DApp/Autosave/`## Feature Lifecycle1. User triggers action (toolbar, menu, keyboard shortcut)2. Action dispatches `CadCommandAction` through the ViewModel3. `CadProjectStore.Apply()` routes to the handler via switch expression4. Handler validates preconditions, mutates `Project` state5. `CadActionResult` is returned with `Snapshot` (compiled state)6. ViewModel reads snapshot, updates UI bindings7. Viewport receives updated mesh data via the snapshot## Adding A New Primitive (Quick Reference)1. Add `CadPrimitiveKind` enum value2. Add `Solid` record in `Core/Solids.cs`3. Add `ShapeNode` class in `Core/Primitives.cs`4. Add `IGeometryBackend.CreateXxx()` method5. Add `DebugBackend.CreateXxx()` stub implementation6. Add feature class extending `PrimitiveFeature` in `CadModel.cs` with `CreateSolid()`7. Add `CadFeatureKind` enum value8. Add `JsonDerivedTypeAttribute`9. Update `CreatePrimitiveFeature()` in `CadProjectStore.cs`10. Update `HandleCreatePrimitive()` if special handling needed
