# UI Principles

## Core UI identity

The UI is an engineering desktop tool.

It is not:
- a SaaS dashboard
- a startup app
- a mobile interface
- a card-heavy system
- a playful design system

## Style principles

- dense
- structured
- technical
- neutral
- controlled
- hierarchy-first

## Layout hierarchy

1. Viewport is the dominant area
2. Toolbar is the main action zone
3. Sidebar is structural
4. Assistant is supportive
5. Tabs are secondary

## UI behavior principles

- modes must be clear
- Sketch and 3D UI states must not be mixed
- buttons must not pretend to work if they do not
- empty state must look intentional, not fake
- assistant must not look like a casual messenger

## Forbidden patterns

- dashboards
- analytics cards
- fake data widgets
- oversized padding
- mobile spacing
- chat bubbles as the default assistant style
- browser visual language
