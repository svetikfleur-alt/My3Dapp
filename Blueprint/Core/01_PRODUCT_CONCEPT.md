# Product Concept

## Product name (working)

Parametric CAD Studio with Engineering Assistant

## Product essence

This product is a desktop-first engineering studio for structured geometric modeling.

It is not:
- a browser-first SaaS tool
- a generic 3D editor
- a casual AI chat app
- an organic sculpting tool

It is:
- a local desktop engineering workspace
- a parametric CAD environment
- a feature-based modeling system
- an assistant-augmented design tool

## Product evolution

Stage 1:
- toy / MVP / controlled prototype

Stage 2:
- reliable engineering tool for real tasks

Stage 3:
- serious assistant-enabled system for complex engineering reasoning, modeling, and structured generation

## Main promise

The studio must help the user:
- model structured geometry
- handle repeatable patterns
- work with features and parameters
- receive engineering help
- gradually trust the system on harder and harder tasks

## Current design focus

Current focus is:
- shell
- layout
- toolbar
- sidebar
- viewport
- assistant panel
- feature workflow concept

The current stage does NOT attempt to solve all CAD complexity.

## Long-term aspiration

The system should eventually support:
- serious modeling work
- structured engineering decision support
- think-and-do workflows
- complex patterned and parameterized forms
- stable growth without architectural collapse
