# Product Scope

## In scope now

- Desktop-first application shell
- Parametric CAD direction
- Sketch mode
- 3D mode
- Basic feature tree
- Basic tool groups
- Assistant panel concept
- Structured geometry
- Repeatable patterns
- Local compute first
- Blueprint-driven implementation

## Explicitly out of scope now

- Organic sculpting
- Artistic freeform modeling
- Browser-first architecture
- Cloud-first dependency
- Enterprise collaboration
- Team workflow systems
- Full manufacturing stack
- Full simulation stack
- Deep assembly workflows
- Advanced CAM workflows
- PDM/PLM

## Scope boundary rule

If a feature introduces major architectural weight but does not improve the current MVP path, it must be postponed.

The current stage values:
- clarity
- stability
- architectural correctness
over
- feature count
