# MVP Definition

## MVP goal

Deliver a stable, understandable desktop CAD Studio shell that can grow.

## MVP includes

- desktop shell
- top toolbar
- left sidebar
- center viewport container
- right assistant shell
- bottom tabs
- Sketch UI state
- 3D UI state
- basic structure tree
- basic tool grouping
- no fake complexity

## MVP does not include

- full CAD engine
- organic modeling
- deep assistant intelligence
- advanced assemblies
- full simulation
- complete pattern system
- production rendering

## MVP success

The MVP is successful when:
- the interface reads as a real engineering tool
- modes are separated
- viewport is dominant
- sidebar reads as structure
- assistant reads as engineering help, not chat app
- the project can grow without rewrite
