# Acceptance Criteria

## Layout

- Viewport is the dominant area
- Top toolbar is compact and tool-based
- Left panel is structural
- Right panel is assistant, not messenger

## Style

- No dashboard patterns
- No cards
- No SaaS look
- No mobile spacing
- Dense and technical UI

## Modes

- Sketch mode is visually distinct
- 3D mode is visually distinct
- Toolbars are different per mode
- No mixing of tool sets

## Assistant

- Not a messenger UI
- Structured output
- Supports modes:
  - Auto
  - Do
  - Think
  - Assist
  - Think & Do

## Architecture

- UI is separate from model logic
- Viewport is a real rendering target in architecture
- No monolithic structure
