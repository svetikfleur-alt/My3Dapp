# Reference Material Usage

This folder is for reference material only.

It may contain:

- screenshots
- cropped UI studies
- notes
- indexing files
- locally saved archives for research

It is not part of the shipping app and should not be treated as first-party product code.

## How to use these references

- extract the behavior or layout idea
- rewrite the requirement in our own words
- implement it in our own architecture
- avoid copying vendor-specific text or exact branded presentation

## Current known sources

- `zoo/` for layout and interaction reference
- `onshape/` for CAD workflow and feature-tree reference
- other CAD folders for narrower UI patterns

## If source code examples are added here later

Do not copy them straight into `AvaloniaApp/` or `Engine/`.

Instead:

1. review the license
2. document the source
3. isolate any intentional imports
4. prefer clean-room reimplementation
