# DIN Rail Clip

- **ID:** `din-rail-clip`
- **Category:** Mounts & fixtures
- **Tags:** din-rail, clip, panel, electronics, mount

## Description

Printable DIN rail clip for control cabinets, electronics panels, and modular tool mounts.

## Parameters

| Key | Default | Unit | Notes |
|---|---:|---|---|
| railWidth | 35 | mm | DIN rail body width |
| clipHeight | 28 | mm | Overall clip height |
| wallThickness | 3 | mm | Printable wall thickness |
| lipDepth | 7 | mm | Retention lip depth |
| screwHoleDiameter | 3.5 | mm | 0 disables mounting hole |

## Geometry notes

Uses the current bracket-style command foundation for a stable MVP body. It is printable and editable, but not yet a full spring-clip mechanical model.
