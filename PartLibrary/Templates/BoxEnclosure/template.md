# Box Enclosure

- **ID:** `box-enclosure`
- **Category:** Enclosures
- **Tags:** box, enclosure, case, electronics, housing

## Description

Parametric enclosure shell for project boxes, control housings, and electronics cases.

## Parameters

| Key | Default | Unit | Notes |
|---|---:|---|---|
| innerWidth | 80 | mm | Interior cavity width |
| innerHeight | 50 | mm | Interior cavity height |
| innerDepth | 40 | mm | Interior cavity depth |
| wallThickness | 3 | mm | Shell wall thickness |
| cornerRadius | 3 | mm | Exterior rounding |

## Geometry notes

Uses the current shell recipe foundation. Good for quick printable enclosure concepts while lid/snap detail is still evolving.
