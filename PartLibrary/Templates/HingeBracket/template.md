# Hinge Bracket

- **ID:** `hinge-bracket`
- **Category:** Brackets
- **Tags:** hinge, bracket, pivot, door, lid

## Description

Starter hinge bracket for lids, lightweight doors, covers, and folding fixtures.

## Parameters

| Key | Default | Unit | Notes |
|---|---:|---|---|
| leafWidth | 30 | mm | Width of each leaf |
| leafLength | 40 | mm | Leaf length |
| thickness | 3 | mm | Leaf thickness |
| pinDiameter | 5 | mm | Hinge pin outer diameter |
| knuckleCount | 3 | count | Between 2 and 5 |

## Geometry notes

The current generator uses the command/feature pipeline to create a strong printable hinge-like body. Fine detail articulation is still limited in this MVP.
