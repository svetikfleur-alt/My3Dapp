# Simple Box

- **ID:** `simple-box`
- **Category:** Enclosures
- **Tags:** box, container, bin, simple, maker

## Description

General-purpose printable box body for simple storage, fixtures, and project organization.

## Parameters

| Key | Default | Unit | Notes |
|---|---:|---|---|
| width | 80 | mm | Overall width |
| depth | 60 | mm | Overall depth |
| height | 40 | mm | Overall height |
| wallThickness | 3 | mm | Shell thickness |
| openTop | 1 | toggle | 1=open top, 0=closed |
| cornerRadius | 2 | mm | Outer softening |

## Geometry notes

Uses the current shell recipe foundation. Good for quick printable containers and layout mockups.
