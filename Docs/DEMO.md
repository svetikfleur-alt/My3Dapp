# My3DApp Demo Flow

## Demo: maker part from template

1. Launch the app
2. Create a new document
3. Open the `Templates` workspace
4. Select `Fan Adapter Plate` or `Mounting Plate`
5. Edit a few parameter values
6. Review the generated script command preview
7. Click `Generate Template Part`
8. Switch to `Prepare`
9. Export STL
10. Save the document as `.umxproj`
11. Reopen the document and verify the workspace/template state restored

## Demo: basic sketch to feature

1. Open `Part Studio`
2. Click `Start Sketch`
3. Select `Top` plane
4. Draw a rectangle or circle
5. Finish Sketch
6. Run `Extrude`
7. Review the result in the tree and viewport
